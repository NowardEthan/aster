# Aster

Canal público dos instaladores do Aster para Windows.

O código-fonte é privado. Este repositório só recebe os binários de cada versão.

## Baixar a última versão

[Releases](https://github.com/NowardEthan/aster/releases/latest)

O arquivo do instalador se chama `Aster-Setup-*.exe`.

## O que não fica aqui

Issues e código-fonte não são acompanhados neste repositório.
